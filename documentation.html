Zoom Breakout Automator

Documentation

Adding The App

Open the Zoom Marketplace authorization link provided by the developer, authorize the app, restart Zoom Desktop, then open a Zoom Meeting and select the app from the Zoom Apps panel.

Using The App

  1. Start or join a Zoom Meeting as host or co-host.
  2. Open Zoom Apps and select Zoom Breakout Automator.
  3. Create or edit a room preset.
  4. Select "Raeume in Zoom anlegen" to create breakout rooms.
  5. Select "Alle oeffnen" or "Alle schliessen" when needed.

Removing The App

Open your Zoom Marketplace account, go to added apps or managed apps, select Zoom Breakout Automator, and choose remove or revoke access.

Data Storage

Room presets are stored locally in the user's browser storage. The app does not send room presets to an external server.
